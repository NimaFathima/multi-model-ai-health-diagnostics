# Data sources

| Dataset | Use | Included in repo? |
|---|---|---|
| NHANES (CDC) | Derive population reference ranges | No - download from https://wwwn.cdc.gov/nchs/nhanes/ . Processed ranges are in `core_phase3/knowledge_base/nhanes_reference_ranges.json` |
| ILPD - Indian Liver Patient Dataset (UCI) | Indian-population liver parameter analysis | Yes (small) |
| Laboratory reference-range tables | Standard adult ranges | Summarised in `reference_ranges.json` |
| ABIM reference ranges | Additional reference source | `abim_reference_ranges.json` |
| Test blood reports | Evaluation | **No** - real patient documents, kept private |

Please follow each dataset's own licence and citation requirements.
